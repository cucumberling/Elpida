# Elpida 系统设计

## 数据流

```
                    ┌─────────────── 总管（调度、监控、管理所有 agent 和 skill）───────────────┐
  行情数据 ─┐        │   技术面 ─┐                                                        │
  基本面数据 ┼─→ 数据库 ─→ 基本面 ─┼─→ 加权 ─→ 判断 ─→ 数据库 ─→ Dashboard               │
  消息采集 ─┘        │   消息面 ─┤       ↑        ↑                                         │
                    │   期权定价 ┘       │ 调权重  │ 规则卡片、风控                          │
                    │              迭代 ←──── 学者（交易方法、行为金融、猪周期研究）            │
                    └──────────────────────────────────────────────────────────────────┘
```

## 原则

1. **能用程序就不用 AI。** 行情、技术指标、期权定价、加权都是确定的代码：便宜、可回测、每次结果一样。
   AI 只用在读文字和做综合判断的地方（消息面、基本面解读、判断、学者、迭代）。
2. **Agent 之间不直接说话，只通过数据库交换。** 分析类 agent 统一交「答卷」（`elpida/signal.py`）：
   品种、依据日期、时间范围、分数 −1…+1、信心 0…1、理由、证据。这样每个 agent 能单独测试、替换，也能逐个统计准确率。
3. **回测不偷看未来。** 每条数据都记「什么时候能看到」；主力换月只用前一天收盘的持仓。
4. **迭代 agent 不直接改线上。** 它提 PR 并附回测结果，人批准合并后，服务器 15 分钟内自动部署。
   权重可以自动调，但每次幅度有上限，全部留记录。
5. **先只给建议。** 模拟盘（SimNow）跑稳后再考虑实盘。
6. **仓库是公开的。** 密钥、账户、访问钥匙只放服务器 `~/elpida-data/`。

## 生猪的关键驱动

| 因素 | 领先期 | 由谁负责 |
|---|---|---|
| 能繁母猪存栏 | 约 10 个月 | 基本面数据 → 基本面 |
| 仔猪价格、补栏 | 约 6 个月 | 基本面数据 → 基本面 |
| 养殖利润、猪粮比 | 几个月 | 基本面（玉米、豆粕期货已在行情数据里） |
| 出栏均重、二次育肥 | 几周到两三个月 | 基本面数据 → 基本面 |
| 冻品库存、屠宰量 | 同步 | 基本面数据 → 基本面 |
| 季节性（春节前旺季） | 每年 | 基本面 |
| 基差、交割 | 越近交割越重要 | 基本面、判断（个人客户交割月前必须平仓） |
| 收储抛储、疫病 | 突发 | 消息采集 → 消息面 |
| 期权隐含波动率、偏斜 | 情绪 | 期权定价 |

## 阶段

| 阶段 | 内容 | 状态 |
|---|---|---|
| 1 | 骨架（数据库、总管、Dashboard、部署）、行情数据、期权定价 | ✅ |
| 2 | 技术面、基本面（养殖利润、母猪手工录入、季节性）、加权（固定权重）、规则版判断 → 每天一条建议 | ✅ |
| 3 | 消息采集、消息面（AI），判断升级为 AI；自动抓取能繁母猪、现货价等基本面数据 | |
| 4 | 回测、每日对答案、各 agent 成绩单、迭代 agent 自动调权重和提 PR | |
| 5 | 学者：知识库、规则卡片、策略假设 | |
| 6 | 模拟盘 → 小资金实盘 | |

## 期权定价说明

- 大商所期货期权是美式，理论价用 CRR 二叉树（标的是期货，漂移为 0），Black-76 作参考。
- 隐含波动率用二分法让二叉树价格等于市场中间价；波动率微笑只用虚值一侧（深度实值期权几乎全是内在价值，反推不准）。
- 期权到期日按「交割月前一个月第 12 个交易日」估算，暂未扣节假日。
- 无风险利率默认 1.5%（环境变量 `ELPIDA_RISK_FREE` 可改）。

## 基本面的成本假设

期货隐含养殖利润 = 生猪期货价 − 估算完全成本。成本 = 料肉比 3.0 ×（65% 玉米期货价 + 20% 豆粕期货价 + 15% × 3000 元/吨）/ 1000
\+ 非饲料成本 5.5 元/公斤（`config.HOG_COST`，料肉比和非饲料成本可用环境变量 `ELPIDA_FCR`、`ELPIDA_NONFEED` 改）。
只是粗估，用来看利润的方向和变化；绝对水平以行业调研数据为准。
